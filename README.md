# CyberSentinel

**AI-assisted threat detection and incident response workspace**

CyberSentinel is a local-first portfolio project built with React, FastAPI, SQLite, scikit-learn and optional Ollama integration. It includes a working demo workflow for authentication, event ingestion, rule-based detections, anomaly scoring, incident triage, ATT&CK technique references, CSV export and an AI investigation assistant.

> This is a development/demo platform, not a production SIEM. Seeded events are simulated. Detection results are educational signals and must be validated before operational use.

## Features

- JWT authentication with registration and login
- Dashboard with event/alert/incident metrics and severity distribution
- Security event ingestion, normalization and search
- Detection rules for repeated authentication failures, suspicious PowerShell and unusual privileged activity
- Isolation Forest anomaly scoring (trained on generated baseline data)
- Incident creation, status changes and analyst notes
- MITRE ATT&CK technique references attached to detections
- Optional local Ollama assistant (default model `llama3`)
- CSV event export and JSON incident report export
- Safe, local simulation endpoints for sample attack-like telemetry
- Light/dark theme and responsive layout

## Stack

- Frontend: React, Vite, Recharts, Lucide React
- Backend: Python 3.12+, FastAPI, SQLAlchemy, SQLite by default
- Detection: scikit-learn IsolationForest
- AI: Ollama HTTP API, optional and never required for core features

## Quick start (Windows PowerShell)

### 1. Backend

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
python -m app.seed
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API docs: http://127.0.0.1:8000/docs

The backend uses SQLite automatically and creates `backend/cybersentinel.db` on first run.

### 2. Frontend (new terminal)

```powershell
cd frontend
npm install
npm run dev
```

Open the URL printed by Vite (normally http://127.0.0.1:5173).

You can also register another account from the login screen.

## Optional local AI

1. Install Ollama from https://ollama.com/
2. In a terminal run:

```powershell
ollama pull llama3
ollama serve
```

3. Ensure `OLLAMA_BASE_URL=http://localhost:11434` and `OLLAMA_MODEL=llama3` in `backend/.env`.
4. Open AI Copilot in CyberSentinel. If Ollama is unavailable, the UI explains how to enable it.

Ollama's chat API is called locally at `/api/chat` with streaming disabled. See [Ollama API documentation](https://docs.ollama.com/api).

## Configuration

Copy `backend/.env.example` to `backend/.env`. Change `SECRET_KEY` before sharing or deploying. For a real deployment, use PostgreSQL, HTTPS, a managed secret store, hardened authentication, audit retention, backups, and a reviewed threat model.

## Important limitations

- Events and attacks generated by the simulator are synthetic.
- Isolation Forest scores are anomaly scores, not calibrated probabilities.
- The local LLM produces analyst assistance, not authoritative verdicts. It receives evidence excerpts and is instructed to distinguish observations from hypotheses.
- No destructive or automatic containment actions are executed.
- The initial version uses SQLite for easy local setup. PostgreSQL can be configured later by changing `DATABASE_URL` and installing a PostgreSQL driver.
- The palette is implemented as editable CSS design tokens. The supplied Pinterest image could not be fetched by the build environment (403), so the current palette is a provisional deep-plum / muted-lilac / cool-mint scheme. Upload the image directly to have the palette matched more closely.
